1. **Universal Knowledge & Source Intelligence:** Transforming thousands of open-source repositories, models, datasets, research corpora, public APIs, and local tools into a classified, deduplicated, license-aware, relationship-mapped, and continuously expanding operational ecosystem (`2,810` raw entries -> `2,280` deduplicated canonical sources + live incremental discovery).
2. **Tri-Model Specialization & Cooperation:**

   - **HEYUKA Core (`heyuka-core`):** Software engineering, isolated sandbox execution verification, formal math (`Decimal.js` / DGI CGI Art. 145), and defensive security auditing.
   - **HEYUKA Vision (`heyuka-vision`):** Multimodal image/DOM/Set-of-Mark analysis, 3D binary `glTF 2.0` synthesis, and visual UI verification.
3. **Resource-Driven Universal Generation:** Producing real, verified artifacts (PDF, XLSX, DOCX, PKZIP, 3D `.glb`, codebases, data analyses) rather than text placeholders.
4. **Evidence-Based Learning Loop (Three Distinct Layers):**
   - *Knowledge Acquisition:* Resumable crawling, SHA-256 deduplication, and 7-layer persistent memory (`persistent-episodic-memory.ts`).
   - *Operational Learning:* Routing optimization and Reflexion failure lessons (`self-evolution-engine.ts`).

5. **Zero-Mandatory-Cost & Local Device Operation:** Core workflows, deterministic generation, and local knowledge retrieval run at `$0.00` mandatory subscription cost, with optional BYOK/external providers.
6. **Confidentiality & Security:** Strict separation between private internal source intelligence (registries, vault paths, system prompts, credentials) and ordinary user chat/public artifacts (`confidentiality-guard.ts`, `secret9_cyber_immune.ts`).
