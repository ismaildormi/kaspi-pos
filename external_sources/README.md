# KASPI POS — External Open-Source Engines & Arena AI (`external_sources/`)

هذا المجلد يضم جميع المصادر المفتوحة الـ 12 (شاملة منصة **Arena AI** الرسمية + **Puck** + المصادر الـ 10) المدمجة داخل **Kaspi AI Studio**:

## 1. قائمة المصادر المفتوحة والروابط المباشرة الكاملة

| الترتيب | اسم المشروع | الرابط المباشر على GitHub | رابط النقل المباشر (Git Clone) | الوظيفة الأساسية في KASPI POS |
| :--- | :--- | :--- | :--- | :--- |
| **01** | **FastChat (Arena UI)** | https://github.com/lm-sys/FastChat | `https://github.com/lm-sys/FastChat.git` | الكود الأصلي لمنصة Arena (الواجهة ونظام المقارنة المزدوجة Side-by-Side وتوجيه النماذج). |
| **02** | **arena-hard-auto** | https://github.com/lm-sys/arena-hard-auto | `https://github.com/lm-sys/arena-hard-auto.git` | أدوات التقييم وحساب الترتيب الرسمي (Bradley-Terry & Elo Rating) من Arena. |
| **03** | **Puck** | https://github.com/puckeditor/puck | `https://github.com/puckeditor/puck.git` | محرر وباني المتاجر الإلكترونية المرئي بالسحب والإفلات (`@measured/puck`) المربوط مباشرة بمخرجات Arena. |
| **04** | **Morphic** | https://github.com/miurla/morphic | `https://github.com/miurla/morphic.git` | محرك بحث بالذكاء الاصطناعي مع إجابات مدعومة بمصادر موثقة (Web + Store RAG). |
| **05** | **Moonshine** | https://github.com/moonshine-ai/moonshine | `https://github.com/moonshine-ai/moonshine.git` | تحويل الكلام إلى نص وتوليد ملفات صوتية WAV حقيقية محلياً على بروسيسور الجهاز. |
| **06** | **Unstract** | https://github.com/Zipstack/unstract | `https://github.com/Zipstack/unstract.git` | تحويل المستندات والملفات (PDF/صور/نصوص) إلى بيانات JSON منظمة وحقنها في المخزون. |
| **07** | **pdfme** | https://github.com/pdfme/pdfme | `https://github.com/pdfme/pdfme.git` | مولّد مستندات PDF ثنائية حقيقية (`%PDF-1.4`) مع محرر قوالب مرئي وحفظ تلقائي. |
| **08** | **DocETL** | https://github.com/ucbepic/docetl | `https://github.com/ucbepic/docetl.git` | استخراج وتصنيف وتلخيص وتحليل البيانات من آلاف النصوص والسجلات وهوامش الربح. |
| **09** | **assistant-ui** | https://github.com/assistant-ui/assistant-ui | `https://github.com/assistant-ui/assistant-ui.git` | واجهة محادثة متكاملة بالذكاء الاصطناعي مبنية بـ React بستايل Google AI Studio. |
| **10** | **OpnForm** | https://github.com/OpnForm/OpnForm | `https://github.com/OpnForm/OpnForm.git` | أداة لبناء النماذج التفاعلية (Forms) مع الأسئلة الشرطية ورفع الملفات والأتمتة. |
| **11** | **LitServe** | https://github.com/Lightning-AI/LitServe | `https://github.com/Lightning-AI/LitServe.git` | تحويل نماذج الذكاء الاصطناعي المحلية والمجانية إلى واجهة برمجية (API) سريعة. |
| **12** | **next-forge** | https://github.com/vercel/next-forge | `https://github.com/vercel/next-forge.git` | قالب متكامل لبدء مشروع SaaS جاهز (حسابات، دفع، قاعدة بيانات، وتعدد المتاجر). |
